미니예나 새 주소 준비

GitHub 주소를 그대로 유지하면서 Cloudflare에 올릴 수 있는 미니예나 ZIP 파일을 생성합니다. 계정 비밀번호나 개인 주문 정보는 포함하지 않습니다.

ZIP 다운로드 후
  1. Cloudflare의 Workers & Pages에서 Pages → Direct Upload을 선택하세요.
  2. 프로젝트 이름을 miniyena로 입력하세요(사용 가능할 경우).
  3. 다운로드한 miniyena-cloudflare.zip을 올리고 배포하세요.
기존 GitHub 사이트는 계속 운영됩니다. 새 주소는 첫 배포 이후 별도 업로드가 필요하며, OneSignal 푸시 알림은 새 주소에 맞는 추가 설정이 필요할 수 있습니다.
