공구노트 · 아이폰에서 앱처럼 쓰는 공동구매 관리 프로그램
(2026-10 업데이트: 다품목 입력 / 가격 미입력 / 판매자 미송·품절 체크)

[누가 사용하나요?]
- 이 프로그램은 공동구매 운영자(사장님)가 직접 사용하는 관리 화면입니다.
- 주문자에게 품절/미송 체크를 맡기지 않습니다. 고객 전용 주문 접수 기능은 없습니다.
- 카톡으로 상품명, 색상, 사이즈, 수량을 받은 뒤 운영자가 입력합니다.

[주문 입력]
1. 하단의 '주문' 또는 홈의 '주문 추가'를 누릅니다.
2. 주문자 이름을 적습니다.
3. 상품명·색상·사이즈와 수량을 입력합니다.
4. 같은 주문자가 여러 상품을 주문했다면 '+ 이 주문자에게 상품 더 추가'를 누릅니다.
5. 가격을 모르거나 아직 정하지 않았다면 판매 단가를 비워 둡니다.
6. '주문 상품 모두 저장'을 누릅니다.
7. 이미 등록한 주문자 카드 아래 '+ 이름 상품 추가'로 나중에 상품을 더 추가할 수도 있습니다.

[가격은 운영자가 나중에]
- 주문자는 가격을 몰라도 됩니다. 주문 등록 시 가격 필수 입력이 아닙니다.
- 단가 미입력 주문은 '가격 입력 필요'로 표시하고 확정 청구액에 포함하지 않습니다.
- 가격이 확정되면 주문 카드에서 '수정'하여 단가를 적습니다.
- 주문자가 가격 미입력 상품을 가지고 있으면 '전액 입금' 완료 처리를 할 수 없습니다.
- 발주 상품에 단가를 나중에 설정하면 해당 발주 상품과 연결된 가격 미입력 주문에 자동 적용됩니다.

[품절 / 미송은 운영자가 직접]
1. 거래처에서 '미송' 또는 '품절' 안내를 받습니다.
2. 앱 하단 '주문'을 누릅니다.
3. 해당 주문자 아래 상품 줄에 있는 '※ 미송' 또는 '품절'을 직접 체크합니다.
4. 미송 상품은 기록을 유지하고 청구액에 포함합니다.
5. 품절 상품은 주문 기록은 유지하되 청구액·고객 주문 수량에서 제외합니다.
6. 이미 돈을 받았다면 필요 환불 금액이 계산되며, 실제 환불 후 앱에 따로 기록합니다.
7. 품절 상품의 거래처 발주도 취소했다면 '상품·수량'에서 발주 수량을 직접 수정합니다.
8. 2개 중 1개만 품절이면 수량 1개씩 별도 주문 줄로 나눈 뒤 한 줄에 품절을 체크합니다.
- 특정 거래처 상품 전체가 미송이라면 '상품·수량'에서 해당 상품의 '※ 미송'을 체크해 연결 주문에 적용할 수도 있습니다.

[기타 기능]
- 공구 여러 개 생성 및 전환
- 카카오톡 주문내용 여러 줄 붙여넣기
- 상품 발주 수량과 주문 수량을 비교하여 남음/부족 표시
- 입금/환불 내역 기록, 정산 안내 복사, CSV 내보내기
- 전체 주문 JSON 백업 및 복원
- 배송비 인원별 자동 분배 없음 (상품금액만 계산)

[아이폰에 앱처럼 설치하려면]
1. ZIP 압축을 풀면 index.html, manifest.webmanifest, sw.js, 아이콘 이미지가 있습니다.
2. 이 파일들을 HTTPS 웹사이트로 배포해야 합니다. 예: 정적 웹 호스팅 서비스에 ZIP 또는 폴더 업로드.
3. 배포한 URL을 iPhone Safari에서 엽니다.
4. Safari 공유 메뉴 -> 홈 화면에 추가 -> 추가.
5. 홈 화면의 공구노트 아이콘을 눌러 사용합니다.

[중요한 보관 안내]
- 주문 데이터는 해당 기기의 브라우저 저장 공간에 저장되며 서버에 업로드되지 않습니다.
- 같은 주소에서 웹앱을 업데이트하면 일반적으로 기존 저장 데이터를 계속 이용할 수 있습니다.
- 새 웹주소, 다른 브라우저, 다른 기기에서는 데이터가 자동으로 연동되지 않습니다.
- Safari 기록이나 앱 데이터를 지우면 주문이 사라질 수 있으므로 설정에서 정기적으로 JSON 백업하세요.
- 받은 HTML 파일을 아이폰 파일 앱에서 바로 여는 것은 데이터 저장·홈 화면 설치가 제한될 수 있습니다.
- 네이버/카카오 등 외부 계정 로그인이나 주문자별 접근제어 기능은 제공하지 않습니다.
